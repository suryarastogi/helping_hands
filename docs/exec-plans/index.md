# Execution Plans

Index for the helping_hands execution plan system.

## Active plans

Plans currently being worked on live in [`active/`](active/).

## Completed plans

Completed plans are archived in [`completed/2026/`](completed/2026/) and
organized by:

- **Daily consolidations** (`YYYY-MM-DD.md`) — all plans completed on a
  given day, rolled up into a single summary.
- **Weekly consolidations** (`Week-N.md`) — weekly summaries aggregating
  daily consolidations.
- **Individual plans** (`vNNN-slug.md`) — detailed plan documents with
  goals, tasks, and file change lists.

## Tracking

- **[PLANS.md](../PLANS.md)** — master index of all completed plans with
  one-line descriptions, referenced from the repo root.
- **[tech-debt-tracker.md](tech-debt-tracker.md)** — ongoing technical
  debt items that don't warrant a full execution plan.

## Conventions

- Plan numbers are monotonically increasing (`v379`, `v380`, ...).
- Active plans move to `completed/` when all tasks are done.
- Daily consolidations capture same-day plan completions.
- Weekly consolidations roll up daily files at week boundaries.
