## Planning Process

1. Plans are created in `exec-plans/active/` with date-stamped or version-stamped filenames
2. Each plan has clear tasks with checkboxes
3. When all tasks are done, move to `exec-plans/completed/`
4. Daily consolidations capture same-day plan completions
5. Weekly summaries roll up daily files at week boundaries
